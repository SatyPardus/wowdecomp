Available as `ModCore.Hooks` or `require("system.hooks")`.

## Functions

### `Hooks.Register(hookName, callback [, priority [, doc]]) → boolean`

Adds a listener. `priority` defaults to `100`; higher runs first. Returns `false` (and logs an error) if `hookName` is missing or `callback` is not a function. `doc` is stored once per hook name and exposed by `GetMetadata`.

Registering the same function twice adds two listeners.

### `Hooks.Unregister(hookName, callback)`

Removes every listener entry whose function equals `callback`.

### `Hooks.HasListeners(hookName) → boolean`

### `Hooks.Fire(hookName, ...) → any`

Calls listeners in priority order under `pcall`. Errors are logged and skipped. Returns the first non-nil result, or `nil`.

### `Hooks.GetMetadata() → table<string, string>`

Map from hook name to the `doc` string passed at registration.

### `Hooks.GetHookList() → string[]`

Sorted names of hooks that have had listeners registered.

## Registration sugar

`Hooks.OnXxx(callback, priority, doc)` is shorthand for `Hooks.Register("OnXxx", ...)`:

```lua
ModCore.Hooks.OnWorldUpdate(function(dt) end, 100)
```

This works for any key starting with `On` that is not already a field of the module.
