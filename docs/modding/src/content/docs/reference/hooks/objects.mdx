---
title: Objects
description: Hooks for the client object manager and targeting.
---

| Hook | Signature | Returns | Fired when |
| --- | --- | --- | --- |
| `OnObjectCreate` | `fun(guid: number, typeId: integer, objectPtr: lightuserdata)` | void | An object is added to the client object manager |
| `OnObjectDestroy` | `fun(guid: number, typeId: integer, objectPtr: lightuserdata)` | void | An object is being removed from the client object manager |
| `OnTargetChanged` | `fun(oldGuid: number, newGuid: number)` | void | The player's locked target changes |

- `typeId` is the client object type id (item, container, unit, player, game object, dynamic object, corpse).
- `objectPtr` cannot be used from Lua. Track the `guid` instead. See [Entity API](/reference/entity-api/).
- `OnTargetChanged` runs after the target is stored and sent to the server. An empty target is GUID `0`.
- GUIDs are doubles; see [argument types](/guides/hooks/#argument-types).
